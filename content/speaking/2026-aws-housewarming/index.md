## Workshop

- **Role**: Workshop co-host
- **Format**: Hands-on technical workshop
- **Date**: May 5, 2026

I co-hosted one of the hands-on workshops at AWS HouseWarming Warsaw, a free technical event held the day before AWS Summit Warsaw 2026. The event focused on practical, code-driven sessions where attendees could build real solutions alongside AWS engineers and Solutions Architects.

The workshop program covered topics including:

- Amazon OpenSearch Service
- Serverless Java migration
- ECS troubleshooting with AWS DevOps Agent
- Building AI agents with Spring AI and Amazon Bedrock
- Lambda Durable Functions with Serverlesspresso

## Event

- **Date**: May 5, 2026
- **Location**: AWS Warsaw office, Generation Park Z, Towarowa 28, Warsaw, Poland
- **Admission**: Free with registration
- **Website**: [AWS HouseWarming Warsaw 2026](https://awshousewarmingwarsaw2026.splashthat.com/)

AWS HouseWarming brought members of the Polish AWS community into the Warsaw office for an afternoon of workshops and conversations with local AWS specialists. It complemented [AWS Summit Warsaw](https://aws.amazon.com/events/summits/warsaw/), held the following day at EXPO XXI.

The format put implementation ahead of presentation slides. Participants worked directly with AWS services and could discuss design choices and troubleshooting with the people running each workshop.
